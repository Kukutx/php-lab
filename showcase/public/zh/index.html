php-lab：四个 PHP 项目，从原生 PHP 到 Drupal

一个 monorepo，里面是几个小而专注的练习，其中三个主题相同：一个虚构的意大利市政府（Comune di Esempio） 和它发布的公告（avvisi）。每个项目在不同的抽象层次上展示同样的思路，都带测试、静态分析和 CI。

GitHub 上的代码 在 Codespaces 里试用

pdo-crud

原生 PHP 8 写的联系人增删改查：PDO、PSR-4、enum、CSRF 和 XSS 防护、PHPUnit。

laravel

公告栏：路由、Eloquent、Form Request、Blade 组件、功能测试。

drupal10

使用 Bootstrap Italia 的市政网站：内容类型、Views、自定义模块和主题。

wordpress

子主题和插件：自定义文章类型、分类法、meta box、REST 字段、Elementor 小工具。

pdo-crud

不用框架写的通讯录，用来展示框架是由哪些基础部件搭起来的。

  • PHP 8.2+
  • PDO
  • Composer PSR-4
  • PHPUnit 11
  • PHPStan level 8
  • PSR-12
  • Bootstrap 5

要点

  • 前端控制器 public/index.php：Web 服务器对外暴露的唯一文件。
  • readonly 值对象、配合 match 使用的带值 enum、构造器属性提升、命名参数。
  • Repository 接口，PDO 实现里只用预处理语句。
  • CSRF token 用 hash_equals 校验；所有值在输出时都做转义。
  • 领域异常转换成 404 / 422 响应。

测试与检查

  • 单元测试和集成测试（内存中的 SQLite）。
  • GitHub Actions 里跑 PHPStan level 8 和 PHP_CodeSniffer。

laravel

快速而完整地走一遍 Laravel：一个市政公告栏，有增删改查、筛选、校验和测试。

  • Laravel 13
  • PHP 8.3
  • Eloquent
  • Form Requests
  • Blade components
  • PHPUnit

要点

  • Route::resource 配一个包含 7 个动作的控制器，路由模型绑定用 slug。
  • 用 Form Request 和 Rule::enum 做校验；模型、校验和视图共用同一个 enum。
  • 模型的 cast、scope 和事件；migration、factory 和 seeder。
  • Blade 布局和可复用组件，Bootstrap 5，不需要 Node 构建。

测试与检查

  • 使用 RefreshDatabase 的功能测试。

可以和用原生 PHP 写的 pdo-crud 对照，看框架替你做了哪些事。

drupal10

按 Designers Italia 的"modello Comuni"做的市政网站，带一个自定义模块和一个 Bootstrap Italia 主题。

  • Drupal 10.6
  • PHP 8.3
  • Drush 13
  • Bootstrap Italia 2.18
  • Twig
  • Drupal coder

要点

  • avviso 内容类型，关联一个分类法（交通、活动、服务、紧急情况）。
  • /avvisi 这个 View：卡片展示、按分类筛选、分页。
  • 自定义模块：路由、控制器、依赖注入的服务、配置表单、区块插件。
  • 基于 Bootstrap Italia 的自定义 Twig 主题（用 npm 安装，不用 CDN）；render array 上带缓存标签。
  • 配置放在 Git 里管理，另有 Drupal 9 升级到 10 和 WCAG 2.1 AA 的笔记。

wordpress

不改核心代码来扩展 WordPress：给同一个市政府做的子主题和公告插件。

  • WordPress
  • PHP 8.3
  • 子主题
  • 自定义文章类型
  • REST API
  • Elementor

要点

  • 基于 Twenty Twenty-One 的子主题：action、filter 和模板层级。
  • comune-avvisi 插件：自定义文章类型、分类法和一个 meta box。
  • 表单的安全处理：nonce、权限检查、输入清理和输出转义。
  • 短代码、通过 REST 暴露的 meta 字段，以及一个自定义 Elementor 小工具。
