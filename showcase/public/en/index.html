php-lab: four PHP projects, from plain PHP to Drupal

A monorepo of small, focused exercises. Three of the four share one theme: a fictional Italian municipality (Comune di Esempio) and its public notices (avvisi). Each project shows the same ideas at a different level of abstraction, with tests, static analysis and CI.

pdo-crud

A contact list written without a framework, to show the building blocks that frameworks are made of.

  • PHP 8.2+
  • PDO
  • Composer PSR-4
  • PHPUnit 11
  • PHPStan level 8
  • PSR-12
  • Bootstrap 5

Highlights

  • Front controller in public/index.php: the only file the web server exposes.
  • readonly value objects, a backed enum with match, constructor promotion, named arguments.
  • A repository interface with a PDO implementation that uses only prepared statements.
  • CSRF token checked with hash_equals; every value is escaped on output.
  • Domain exceptions mapped to 404 / 422 responses.

Tests and checks

  • Unit and integration tests (in-memory SQLite).
  • PHPStan level 8 and PHP_CodeSniffer in GitHub Actions.

laravel

A quick but complete tour of Laravel: a municipal notice board with CRUD, filters, validation and tests.

  • Laravel 13
  • PHP 8.3
  • Eloquent
  • Form Requests
  • Blade components
  • PHPUnit

Highlights

  • Route::resource with a seven-action controller and route model binding by slug.
  • Validation with a Form Request and Rule::enum; one enum shared by the model, the validation and the views.
  • Model casts, scopes and events; migrations, factories and seeders.
  • A Blade layout and reusable components, Bootstrap 5 with no Node build.

Tests and checks

  • Feature tests with RefreshDatabase.

Compare it with pdo-crud, written in plain PHP, to see what the framework does for you.

drupal10

A municipal website built on the Designers Italia "modello Comuni", with a custom module and a Bootstrap Italia theme.

  • Drupal 10.6
  • PHP 8.3
  • Drush 13
  • Bootstrap Italia 2.18
  • Twig
  • Drupal coder

Highlights

  • An avviso content type that references a taxonomy (traffic, events, services, emergencies).
  • A /avvisi View with cards, an exposed category filter and pagination.
  • Custom module: routing, controller, services with dependency injection, a configuration form, a block plugin.
  • Custom Twig theme on Bootstrap Italia (installed with npm, no CDN); cache tags on render arrays.
  • Configuration managed in Git, with notes on the 9 → 10 upgrade and on WCAG 2.1 AA.

wordpress

Extending WordPress without touching core: a child theme and a notices plugin for the same municipality.

  • WordPress
  • PHP 8.3
  • Child theme
  • Custom post type
  • REST API
  • Elementor

Highlights

  • A Twenty Twenty-One child theme: actions, filters and the template hierarchy.
  • The comune-avvisi plugin: a custom post type, a taxonomy and a meta box.
  • Safe form handling: nonces, capability checks, sanitisation and escaping.
  • A shortcode, a meta field exposed through REST, and a custom Elementor widget.

More documentation

  • Elementor notes
  • /wp-admin login in the demo
