php-lab: quattro progetti PHP, dal PHP puro a Drupal

Un monorepo di esercizi piccoli e mirati; tre su quattro condividono lo stesso tema: un comune di fantasia (Comune di Esempio) e i suoi avvisi al pubblico. Ogni progetto mostra le stesse idee a un diverso livello di astrazione, con test, analisi statica e CI.

pdo-crud

Una rubrica di contatti scritta senza framework, per mostrare i mattoni con cui i framework sono costruiti.

  • PHP 8.2+
  • PDO
  • Composer PSR-4
  • PHPUnit 11
  • PHPStan livello 8
  • PSR-12
  • Bootstrap 5

Punti principali

  • Front controller in public/index.php: l'unico file esposto dal web server.
  • Value object readonly, enum tipizzata con match, constructor promotion, named arguments.
  • Interfaccia Repository con un'implementazione PDO che usa solo prepared statement.
  • Token CSRF verificato con hash_equals; ogni valore è sottoposto a escape in output.
  • Eccezioni di dominio tradotte in risposte 404 / 422.

Test e controlli

  • Test unitari e di integrazione (SQLite in memoria).
  • PHPStan livello 8 e PHP_CodeSniffer in GitHub Actions.

laravel

Una panoramica rapida ma completa di Laravel: una bacheca degli avvisi del comune con CRUD, filtri, validazione e test.

  • Laravel 13
  • PHP 8.3
  • Eloquent
  • Form Requests
  • Blade components
  • PHPUnit

Punti principali

  • Route::resource con un controller a 7 azioni e route model binding tramite slug.
  • Validazione con Form Request e Rule::enum; una sola enum condivisa da modello, validazione e viste.
  • Cast, scope ed eventi del modello; migration, factory e seeder.
  • Layout Blade e componenti riutilizzabili, Bootstrap 5 senza build Node.

Test e controlli

  • Feature test con RefreshDatabase.

Confrontalo con pdo-crud, scritto in PHP puro, per vedere che cosa fa il framework al posto tuo.

drupal10

Un sito comunale costruito sul "modello Comuni" di Designers Italia, con un modulo custom e un tema Bootstrap Italia.

  • Drupal 10.6
  • PHP 8.3
  • Drush 13
  • Bootstrap Italia 2.18
  • Twig
  • Drupal coder

Punti principali

  • Tipo di contenuto avviso con riferimento a una tassonomia (viabilità, eventi, servizi, emergenze).
  • View /avvisi con card, filtro esposto per categoria e paginazione.
  • Modulo custom: routing, controller, servizi con dependency injection, form di configurazione, plugin di blocco.
  • Tema Twig custom su Bootstrap Italia (installato con npm, senza CDN); cache tag sui render array.
  • Configurazione versionata con Git, con appunti sull'aggiornamento 9 → 10 e su WCAG 2.1 AA.

Altra documentazione

  • Procedura di aggiornamento da Drupal 9 a 10 (in inglese)
  • Basi di accessibilità (WCAG 2.1 AA) (in inglese)
  • Accesso all'amministrazione nella demo

wordpress

Estendere WordPress senza toccare il core: un tema child e un plugin di avvisi per lo stesso comune.

  • WordPress
  • PHP 8.3
  • Tema child
  • Custom post type
  • REST API
  • Elementor

Punti principali

  • Tema child di Twenty Twenty-One: action, filter e gerarchia dei template.
  • Plugin comune-avvisi: custom post type, tassonomia e un meta box.
  • Gestione sicura dei form: nonce, controllo dei permessi, sanitizzazione ed escape.
  • Shortcode, campo meta via REST e un widget Elementor custom.

Altra documentazione

  • Appunti su Elementor (in inglese)
  • Accesso a /wp-admin nella demo
